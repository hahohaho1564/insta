# 뷰티판다 카드뉴스 자동 제작 (추가 비용 0원)

매주 평일(월~금)용 카드뉴스 5개를 만들어 드립니다. 인스타그램 게시는 원장님이 직접 하세요.

```
[월요일]  원장님 → Claude: "이번 주 카드뉴스 만들어줘"
          Claude: 주제 5개 제안 → 원고 작성 → 힉스필드 무제한 모드로 사진 생성(크레딧 0) → GitHub 작업함에 넘김
          GitHub: 카드뉴스 5개 완성 → 글마다 이슈 알림 (이미지 zip + 캡션)
[매일]    그날 글의 zip을 받아서 인스타그램에 여러 장 게시물로 올리기
```

| 항목 | 비용 |
|---|---|
| 원고 | Claude 채팅 (지금 쓰시는 Claude 요금제 안에서) |
| 사진 | 힉스필드 무제한 모드 (지금 쓰시는 요금제 안에서, 크레딧 0) |
| 카드뉴스 제작 | GitHub 공개 저장소 자동 실행 (무료) |

피드 목표는 **뷰티샵 원장님을 모으는 것**입니다. (`config.yaml`의 `goal`)

---

## 처음 한 번만 하는 설정
1. **GitHub 저장소**에 이 폴더 내용 올리기 (Public). `.github` 폴더는 웹 업로드가 안 되니 Claude에게 부탁하세요.
2. **Settings → Actions → General → Workflow permissions**를 **Read and write permissions**로.
3. **Actions → 처음 설정 (한 번만) → Run workflow** → Issues에 "📥 Claude 작업함" 생성.
4. **claude.ai 프로젝트** 만들고 지침에 붙여넣기:
   ```
   뷰티판다 인스타 카드뉴스 담당이야. 저장소: https://github.com/<아이디>/<저장소>
   "이번 주 카드뉴스 만들어줘"라고 하면 저장소의 CLAUDE_GUIDE.md를
   https://raw.githubusercontent.com/<아이디>/<저장소>/main/CLAUDE_GUIDE.md 에서 읽고 그대로 진행해.
   수정 요청이나 급한 공지도 같은 안내서를 따라.
   ```
5. 휴대폰에 **GitHub 앱** 설치 (완성 알림용).

## 평소 사용법
- **월요일**: 프로젝트 채팅에서 **"이번 주 카드뉴스 만들어줘"**. 사진 만드는 데 20~30분 걸려요.
- **완성 알림이 오면**: 이슈에서 **zip 링크**를 누르면 이미지(01, 02, …)와 캡션.txt가 한 번에 받아져요.
  휴대폰에서는 이미지를 하나씩 눌러 길게 눌러 저장해도 됩니다.
- **인스타에 올리기**: 여러 장 게시물로 01부터 순서대로 선택 → 캡션 붙여넣기.
- **고칠 게 있으면**: Claude에게 "10/7 글 표지 더 짧게"처럼 말하기. 같은 이슈가 새 버전으로 바뀌어요.
- **올리기 전 확인** 항목(법 규정, 금액 등)이 있으면 꼭 확인하고 올리세요.
- **급한 글·공지**: Claude에게 "오늘 품절 공지 하나 만들어줘".
- 올린 글의 이슈는 닫아두면 정리가 편해요.

## 설정 바꾸기 (`config.yaml`)
- 정보·마케팅 비율: `rotation` (예: `[info, info, mkt]`)
- 장수, 글당 사진 수: `slides.count`, `slides.max_photos`
